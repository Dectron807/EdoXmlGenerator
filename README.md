Профессиональное настольное Windows-приложение на **.NET 8 (WPF)** для автоматизированного создания, проверки и выгрузки юридически значимых электронных документов для систем операторов ЭДО (**Контур.Диадок**, **СБИС / Тензор**, **1С-ЭДО**, **Такском**, **Калуга Астрал**).

---

## 🚀 Основные возможности

### 1. Формирование официального УПД формата 5.03
- **Соответствие законодательству РФ**: Полная реализация Приказа ФНС России от 19.12.2023 № **ЕД-7-26/970@** (актуальный формат 2024–2026 гг., КНД 1115131).
- **Схема XSD**: Строгая валидация по официальной схеме `ON_NSCHFDOPPR_1_997_01_05_03_05.xsd` прямо при формировании документа.
- **Поддержка статусов**:
  - **Статус 1 (`СЧФДОП`)** — совмещенный счет-фактура и передаточный документ (акт/накладная).
  - **Статус 2 (`ДОП`)** — первичный передаточный документ (без НДС / УСН).
  - **`СЧФ`** — счет-фактура по НДС.
  - **`ИСПР`** — структурное исправление ранее выставленного документа.

### 2. Поддержка всех специальных реквизитов УПД
- **Строка 3 (Грузоотправитель)**: отметка «он же» с формированием регламентного тега `<ОнЖе>он же</ОнЖе>` внутри `<ГрузОт>`.
- **Строка 4 (Грузополучатель)**: автоматическое совпадение с покупателем.
- **Строка 5 (Платежно-расчетные документы)**: ввод номера, даты и суммы платежки (`<СвПРД>`).
- **Строка 5а (Документ об отгрузке)**: наименование, номер и дата первичного документа (`<ДокПодтвОтгрНом>`).
- **Строка 8 (Идентификатор госконтракта)**: реквизит `ИдГосКон` (20–25 знаков для ГОЗ и казначейства).
- **Графа 1б (ТН ВЭД ЕАЭС)**: 10-значный код вида товара (`КодВидТов`).
- **Графа 6 (Акциз)**: сумма акциза (`<СумАкциз>`) или признак `<БезАкциз>без акциза</БезАкциз>`.
- **Графа 14 (Прослеживаемость)**: стоимость прослеживаемого товара без налога (`СтТовБезНДСПрослеж`) по Постановлению Правительства № 534, а также РНПТ и количественная единица.
- **Маркировка «Честный ЗНАК»**: коды идентификации (КИЗ) и транспортные упаковки.
- **Машиночитаемые доверенности (МЧД)**: блок `<СвДоверЭл>` с регистрационным номером (GUID 36 знаков), датой выдачи и хранилищем распределенного реестра ФНС России.
- **Строки передачи [10]–[16]**: основание передачи, ответственные лица и экономический субъект.

### 3. Интеллектуальный импорт из Excel
- Чтение данных напрямую из бланка УПД (`Blank formy' UPD.xlsx`) или произвольных таблиц Excel.
- Автоматическое распознавание колонок по графам: **А, 1, 1а, 1б, 2, 2а, 3, 4, 5, 6, 7, 10, 10а, 11, 14**.
- Распознавание шапки (номер счета-фактуры, продавец, покупатель, ИНН/КПП).

### 4. Каталог 50 первичных документов РФ
Встроенный структурированный каталог форм, сгруппированных по категориям:
- **Продажи и услуги**: Счёт на оплату, Акт выполненных работ, ТОРГ-12, Спецификация, Коммерческое предложение, Счёт-оферта.
- **Логистика и транспорт**: Путевые листы (легковой, грузовой), Транспортная накладная, Акт приема-передачи ТС, Заявка на перевозку, Акт инвентаризации (ИНВ-3).
- **Финансы и банк**: Платёжное поручение (форма 0401060 по Положению ЦБ РФ № 762-П), ПКО (КО-1), РКО (КО-2), Акт сверки взаиморасчетов, Авансовый отчет (АО-1).
- **Кадры**: Трудовой договор, Приказы о приеме, увольнении, отпуске, премировании, Заявления, Доверенность (М-2).
- **Договоры**: Поставка, Подряд, Аренда, Оказание услуг, Беспроцентный займ, Соглашение о конфиденциальности (NDA), Договор с самозанятым.
- **Регистрация бизнеса**: Заявления Р11001, Р21001, Уведомления об УСН.

### 5. Удобство интерфейса (UX)
- **100% подсказок (Placeholders)**: каждое поле снабжено наглядным примером правильного формата (ИНН, КПП, БИК, счета, даты, суммы, паспортные данные).
- **Подсветка активного документа**: наглядное выделение синим акцентом выбранного документа в боковом меню.
- **Сохранение в любую папку**: при выгрузке XML открывается стандартный системный проводник с автоматической подстановкой регламентного имени файла ФНС.
- **Сохранение шаблонов**: возможность сохранять шаблоны документов в форматах `.upd.xml` и `.json`.

## 📁 Структура проекта

```text
EdoXmlGenerator/
├── Models/              # Модели документов (Upd53Doc, CatalogDocument, FieldDef)
├── ViewModels/          # MVVM-модели (MainViewModel, UpdFormViewModel, CatalogFormViewModel)
├── Views/               # XAML-представления (UpdFormView, CatalogFormView, PreviewView)

├── Templates/           # Встроенные шаблоны документов
└── Data/                # Справочники единиц измерения и кодов
```

## 🛠 Сборка из исходного кода

### Требования
- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- Windows 10 / 11 (64-bit)

### Команды для сборки и запуска

```bash
# Клонирование репозитория
git clone https://github.com/Dectron807/EdoXmlGenerator.git
cd EdoXmlGenerator

# Сборка проекта
dotnet build EdoXmlGenerator/EdoXmlGenerator.csproj

# Запуск приложения
dotnet run --project EdoXmlGenerator/EdoXmlGenerator.csproj

# Публикация релиза
dotnet publish EdoXmlGenerator/EdoXmlGenerator.csproj -c Release -r win-x64 --self-contained false -o ./Release
```
