**«Глав.Документ»** — современное настольное Windows-приложение на **.NET 8 (WPF)** для автоматизированного создания, проверки и выгрузки юридически значимых электронных документов для систем операторов ЭДО (**Контур.Диадок**, **СБИС / Тензор**, **1С-ЭДО**, **Такском**, **Калуга Астрал**).

> 💡 **Скачать готовую программу:**  
> Готовый установщик для Windows и портативная версия доступны на странице [**Releases**](https://github.com/Dectron807/EdoXmlGenerator/releases).

## 🚀 Ключевые возможности

### 1. Формирование официального УПД формата 5.03
- **Соответствие законодательству РФ**: Полная реализация Приказа ФНС России от 19.12.2023 № **ЕД-7-26/970@** (актуальный формат 2024–2026 гг., КНД 1115131).
- **Схема XSD**: Строгая валидация по официальной схеме `ON_NSCHFDOPPR_1_997_01_05_03_05.xsd` перед выгрузкой.
- **Поддержка статусов**:
  - **Статус 1 (`СЧФДОП`)** — совмещенный счет-фактура и передаточный документ (акт/накладная).
  - **Статус 2 (`ДОП`)** — первичный передаточный документ (без НДС / УСН).
  - **`СЧФ`** — счет-фактура по НДС.
  - **`ИСПР`** — структурное исправление ранее выставленного документа.

### 2. Поддержка специальных реквизитов УПД
- **Строка 3 (Грузоотправитель)**: отметка «он же» с формированием регламентного тега `<ОнЖе>он же</ОнЖе>` внутри `<ГрузОт>`.
- **Строка 4 (Грузополучатель)**: автоматическое совпадение с покупателем.
- **Строка 5 (Платежно-расчетные документы)**: ввод номера, даты и суммы платежки (`<СвПРД>`).
- **Строка 5а (Документ об отгрузке)**: наименование, номер и дата первичного документа (`<ДокПодтвОтгрНом>`).
- **Строка 8 (Идентификатор госконтракта)**: реквизит `ИдГосКон` (20–25 знаков для ГОЗ и казначейства).
- **Графа 1б (ТН ВЭД ЕАЭС)**: 10-значный код вида товара (`КодВидТов`).
- **Графа 6 (Акциз)**: сумма акциза (`<СумАкциз>`) или признак `<БезАкциз>без акциза</БезАкциз>`.
- **Графа 14 (Прослеживаемость)**: стоимость товара без налога (`СтТовБезНДСПрослеж`) по Постановлению № 534, а также РНПТ и единица измерения.
- **Маркировка «Честный ЗНАК»**: коды идентификации (КИЗ) и транспортные упаковки.
- **Машиночитаемые доверенности (МЧД)**: блок `<СвДоверЭл>` с номером (GUID 36 знаков), датой выдачи и хранилищем распределенного реестра ФНС России.
- **Строки передачи [10]–[16]**: основание передачи, ответственные лица и экономический субъект.

### 3. Интеллектуальный импорт из Excel
- Чтение данных напрямую из официального бланка УПД (`Бланк формы УПД.xlsx`) или произвольных таблиц Excel.
- Автоматическое распознавание колонок по графам: **А, 1, 1а, 1б, 2, 2а, 3, 4, 5, 6, 7, 10, 10а, 11, 14**.

## 📚 Полный перечень поддерживаемых документов (50 форм)

Все формы снабжены **100% подсказками (placeholders)** с примерами заполнения, автоподсчетом сумм и выгрузкой в XML.

```text

├── Models/              # Модели документов (Upd53Doc, CatalogDocument, FieldDef)

```

## 🛠 Сборка из исходного кода

### Требования
- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- Windows 10 / 11 (64-bit)

### Команды для сборки и запуска

```bash
# Клонирование репозитория
git clone https://github.com/Dectron807/EdoXmlGenerator.git
cd EdoXmlGenerator

# Сборка проекта
dotnet build EdoXmlGenerator/EdoXmlGenerator.csproj

# Запуск приложения
dotnet run --project EdoXmlGenerator/EdoXmlGenerator.csproj
```
